# The Sweet Spot Bakery

A JavaFX-based application for bakery management, including a shopping cart, product management, and receipt generation.

## Features
* **Product Catalog:** Browse and manage bakery items.
* **Shopping Cart:** Add products to cart and process checkouts.
* **Receipts:** Generate and export digital receipts.
* **Dashboard:** Monitor bakery operations.

## Technologies Used
* **Language:** Java
* **GUI Framework:** JavaFX
* **Database:** SQL (See `TheSweetSpotBakery.sql` for schema setup)
* **IDE/Build:** NetBeans / Ant (`build.xml`)

## Getting Started

1. Set up your SQL database using the `src/TheSweetSpotBakery.sql` script.
2. Update the database connection credentials in the Java code (`DBConnection.java` or similar) to match your local SQL server.
3. Open the project in NetBeans (or any Java IDE).
4. Build and run the `TheSweetSpot.java` main class.
